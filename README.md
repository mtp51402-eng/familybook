# കുടുംബ പുസ്തകം (അഡ്മിൻ + കുടുംബാംഗങ്ങൾ)

ലിങ്ക് തുറന്ന് കയറാവുന്ന സാധാരണ വെബ് ആപ്പ്. claude.ai അക്കൗണ്ട് ആർക്കും വേണ്ട.

## ആർക്ക് എന്ത് ചെയ്യാം

- **അഡ്മിൻ (നിങ്ങൾ):** അഡ്മിൻ പാസ്‌വേഡ് കൊണ്ട് കയറും. എല്ലാവരെയും ആധാർ ഉൾപ്പെടെ കാണാം, തിരുത്താം, ഡിലീറ്റ് ചെയ്യാം. ബാക്കപ്പ്, CSV, അംഗങ്ങളുടെ PIN മാറ്റൽ എന്നിവയും.
- **കുടുംബാംഗം:** കുടുംബ കോഡ് + പേര് + സ്വന്തം PIN കൊണ്ട് കയറും. എല്ലാവരെയും കുടുംബ വൃക്ഷത്തിൽ കാണാം, പക്ഷേ ആധാറിന്റെ അവസാന 4 അക്കം മാത്രം. സ്വന്തം ചേർത്തവ മാത്രം തിരുത്താം (അതിൽ സ്വന്തം ആധാർ പൂർണ്ണമായി കാണാം). പുതിയ അംഗങ്ങളെ ചേർക്കാം. ഡിലീറ്റ് ഇല്ല.
- ആധാർ മറച്ചുവെക്കുന്നത് ഫോണിൽ അല്ല, സെർവറിൽ ആണ്. അതായത് മറ്റുള്ളവരുടെ ഫോണിലേക്ക് പൂർണ്ണ നമ്പർ അയക്കുന്നേയില്ല.

## സെറ്റപ്പ് (ഒരിക്കൽ, ഏകദേശം 20 മിനിറ്റ്, സൗജന്യം)

### 1. Firebase (ഡാറ്റാബേസ്)
1. console.firebase.google.com ൽ Google അക്കൗണ്ട് കൊണ്ട് കയറി **Add project** അമർത്തി ഒരു പേര് കൊടുക്കുക (Analytics വേണ്ട).
2. ഇടത് മെനുവിൽ **Build → Firestore Database → Create database**. ലൊക്കേഷൻ ഇന്ത്യയോട് അടുത്തത് (ഉദാ: `asia-south1` മുംബൈ). **Production mode** തിരഞ്ഞെടുക്കുക (ആർക്കും നേരിട്ട് വായിക്കാൻ പറ്റാത്ത മോഡ്, ശരിയാണ്).
3. മുകളിൽ ⚙ **Project settings → Service accounts → Generate new private key**. ഒരു `.json` ഫയൽ ഡൗൺലോഡ് ആകും. ഇത് രഹസ്യമാണ്, ആർക്കും അയക്കരുത്, GitHub ൽ ഇടരുത്.

### 2. GitHub
github.com ൽ പുതിയ repository ഉണ്ടാക്കി ഈ ഫോൾഡറിലെ എല്ലാ ഫയലുകളും (`api` ഫോൾഡർ ഉൾപ്പെടെ) upload ചെയ്യുക. **ഘട്ടം 1-ലെ .json ഫയൽ ഇവിടെ ഇടരുത്.**

### 3. Vercel
1. vercel.com ൽ GitHub വഴി കയറി **Add New → Project** ൽ ആ repository തിരഞ്ഞെടുക്കുക.
2. **Deploy** അമർത്തുന്നതിന് മുമ്പ് **Environment Variables** ൽ ഇവ ചേർക്കുക:

| പേര് | വില |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | ഘട്ടം 1-ലെ .json ഫയൽ ടെക്സ്റ്റ് എഡിറ്ററിൽ തുറന്ന് മുഴുവൻ ഉള്ളടക്കവും കോപ്പി ചെയ്ത് ഇവിടെ പേസ്റ്റ് ചെയ്യുക |
| `ADMIN_PASSWORD` | നിങ്ങളുടെ അഡ്മിൻ പാസ്‌വേഡ് (നീളമുള്ളത്, ഉദാ: 12 അക്ഷരമെങ്കിലും) |
| `FAMILY_CODE` | കുടുംബത്തിന് കൊടുക്കുന്ന കോഡ് (ഉദാ: ഒരു വാക്കും നമ്പറും) |
| `TOKEN_SECRET` | ഏതെങ്കിലും നീളമുള്ള ക്രമരഹിത അക്ഷരങ്ങൾ (കുറഞ്ഞത് 32). ആരോടും പറയേണ്ട |

3. **Deploy** അമർത്തുക. `https://നിങ്ങളുടെ-പേര്.vercel.app` എന്ന ലിങ്ക് കിട്ടും.

### 4. ഉപയോഗം
- ലിങ്ക് തുറന്ന് **അഡ്മിൻ** ടാബിൽ പാസ്‌വേഡ് കൊടുത്ത് കയറി ആദ്യ അംഗങ്ങളെ ചേർക്കുക.
- കുടുംബത്തിന് **ലിങ്കും കുടുംബ കോഡും** WhatsApp ൽ അയക്കുക. അവർ ആദ്യമായി കയറുമ്പോൾ "ആദ്യമായി വരുന്നു" ടിക് ചെയ്ത് പേരും പുതിയ PIN-ഉം വെക്കണം. പിന്നീട് അതേ പേരും PIN-ഉം മതി.
- ആരെങ്കിലും PIN മറന്നാൽ: കൂടുതൽ → "അംഗങ്ങളുടെ ലോഗിൻ" → PIN മാറ്റുക.
- പഴയ ഫോൺ ആപ്പിലെ വിവരങ്ങൾ: അതിൽ "ബാക്കപ്പ് ഡൗൺലോഡ്" എടുത്ത്, ഇതിൽ അഡ്മിൻ ആയി കയറി "കൂടുതൽ → ഫയൽ തിരഞ്ഞെടുക്കുക" വഴി ചേർക്കുക.
- ഫോണിൽ ആപ്പ് പോലെ: Android Chrome ൽ ⋮ → Add to Home screen, iPhone Safari ൽ Share → Add to Home Screen.

## അറിഞ്ഞിരിക്കേണ്ടത്
- 5 തവണ തെറ്റായ PIN കൊടുത്താൽ ആ പേര് 10 മിനിറ്റ് ലോക്ക് ആകും.
- വിവരങ്ങൾ Google Firestore ൽ സൂക്ഷിക്കും. സൗജന്യ പരിധി ഒരു കുടുംബത്തിന് വളരെ കൂടുതലാണ്.
- മറ്റൊരാൾ ചേർത്ത വിവരം മറ്റൊരാൾ ഒരേ സമയം മാറ്റുന്നത് ഒഴിവാക്കാൻ ഓരോ അംഗവും അവർ ചേർത്തവ മാത്രമേ മാറ്റൂ. സ്ക്രീൻ ഓരോ 45 സെക്കൻഡിലും പുതുക്കും.
- കുടുംബ കോഡ്/അഡ്മിൻ പാസ്‌വേഡ് മാറ്റണമെങ്കിൽ Vercel ലെ Environment Variables മാറ്റി Redeploy ചെയ്യുക.
